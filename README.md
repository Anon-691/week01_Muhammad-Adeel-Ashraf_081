## CarDemo

The CarDemo project represents a simple car using Java classes and objects.

### Features
- Private attributes
- Default constructor
- Parameterized constructor
- Setter and getter methods
- Start engine
- Stop engine
- Drift
- Display car details

This project was created to understand how objects store data and perform different actions.

---

## CalculatorDemo

The CalculatorDemo project represents a basic calculator that performs common mathematical operations.

### Features
- Default constructor
- Parameterized constructor
- Setter and getter methods
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Display calculator information
- Prevents calculations when the calculator is turned off
- Handles division by zero
